---

## 1. 概要

ブラウザだけで動くタイピング練習ゲーム。ひらがなをローマ字で打つ「日本語モード」と、
プログラムの短いコードを打つ「プログラミングモード」の2つを持つ。
公開URL: `/tools/typing-japanese`

すべてクライアントサイドで完結し、入力内容をサーバーへ送らない。
スコアの永続化（localStorage 等）は**実装されていない**。

## 2. 画面構成

`GameState` は `'home' | 'playing' | 'result'` の3状態で、1つの React コンポーネント
`TypingGame.tsx` が状態に応じて出し分ける。ページ遷移はしない。

### 2.1 ホーム画面（`home`）

上から順に以下を置く。

| 区画 | 内容 |
|---|---|
| モード | タブ2つ: 「日本語」/「プログラミング」 |
| 難易度 | ラジオ3つ。日本語=やさしい/ふつう/むずかしい、プログラミング=入門/基礎/実践 |
| 言語 | **プログラミングモードのときだけ表示**。すべて/Python/JavaScript/HTML/CSS |
| 時間 | スライダー（30〜120秒、30秒刻み）＋ 30秒/60秒/120秒のボタン |
| スタート | ボタン1つ |

モードを切り替えると難易度と言語が初期値へ戻る（日本語→`normal`、プログラミング→
`beginner` + `all`）。

### 2.2 プレイ画面（`playing`）

- 左上に「PLAYING」バッジ、右上に残り秒数（等幅・大きめ）
- 中央のカードにお題（`question`）を 4xl・等幅で表示
- その下の枠に、これまでに打った文字（`userInput`）と点滅カーソル

プログラミングモードのときだけ、お題の文字を1文字ずつ走査して
`/[^a-zA-Z0-9 ]/` に当たる文字（記号）を太字＋アンバー色で強調する。
**半角スペースはこの正規表現から除外されているため、強調されない。**

### 2.3 結果画面（`result`）

完了問題数 / 正解文字数 / 誤入力数 / 正解率(%) の4枚のカードと「ホームに戻る」ボタン。

## 3. 問題データ

`src/features/typing-japanese/problems/*.json` を `import.meta.glob` で eager 読み込み。
1問の形は次のとおり。

```ts
interface Problem {
  question: string;          // 画面に出すお題
  answers: string[];         // 正解として受け付ける入力（複数表記可）
  language?: ProgrammingLanguage;  // プログラミングモードのみ
}
```

| ファイル | 問題数 | 答えに半角スペースを含む問題数 |
|---|---:|---:|
| `easy.json` | 52 | 0 |
| `normal.json` | 50 | 0 |
| `hard.json` | 49 | 0 |
| `programming-beginner.json` | 40 | 27 |
| `programming-intermediate.json` | 40 | 27 |
| `programming-advanced.json` | 30 | 28 |

（件数は `problems/*.json` をスクリプトで数えた実測値）

つまり**スペースキーを打つ必要があるのはプログラミングモードだけ**で、
そこでは大半の問題にスペースが含まれる。

## 4. ゲーム進行のロジック（`useTypingGame.ts`）

### 4.1 開始

1. 選択中のモード・難易度から JSON を1つ選ぶ
   （プログラミングは `programming-<難易度>.json`、日本語は `<難易度>.json`）
2. プログラミングモードなら言語で絞り込む
   （`all` は全件、それ以外は `language === 選択言語 || language === 'common'`）
3. Fisher–Yates でシャッフルし、先頭 **50問** を取る（`MAX_PROBLEMS = 50`）
4. 0問なら即 `result` へ。1問以上あれば `playing` へ

### 4.2 入力判定

`document` の `keydown` を購読する（入力欄への focus は使わない）。

- Ctrl / Meta / Alt との同時押しは無視
- スペースキーは `preventDefault()` してからスペースとして扱う（ページのスクロール防止）
- `event.key.length !== 1` のキー（Shift, Enter, 矢印など）は無視

1文字受け取るたびに、

1. 日本語モードは小文字化し、プログラミングモードはそのまま、これまでの入力に足す
2. `answers` のうち、その新しい入力文字列で**前方一致**するものを絞る
3. 候補が0本 → 誤入力。`wrongChars` を +1 して**入力は伸ばさない**（打ち直せる）
4. 候補があれば入力を確定して表示を更新
5. 候補の中に**完全一致**するものがあれば、その問題はクリア

複数のローマ字表記に対応するための仕組みがこの前方一致であり、
例えば「ありがとう」には `arigato` / `arigatoo` / `arigatou` が登録されている。

### 4.3 クリア時のスコア加算

```ts
correctChars: prev.correctChars + newInput.length
completedProblems: prev.completedProblems + 1
```

`accuracy = correctChars / (correctChars + wrongChars) * 100`

### 4.4 次の問題・終了

- クリアすると入力をクリアして次の問題へ
- 最後の問題をクリアすると `result` へ
- 残り時間が 0 になると `result` へ

### 4.5 タイマー

`playing` の間、`setInterval` で1秒ごとに `timeLeft` を1減らす。
`useEffect` の依存配列に `timeLeft` が入っているため、
1秒ごとにインターバルが破棄・再生成される作りになっている。

## 5. 現行仕様で分かっている課題

改修の出発点として、コードから読み取れる範囲で挙げる。
（動作検証の結果は別途 `review-findings.md` に記録する）

1. **スペースキーを押す箇所が画面から分からない** ← 本改修の主題。
   `x = 5` のようなお題で、記号 `=` は色付きで強調されるのに、
   その両側の半角スペースは何も表示されない。入力欄も同様で、
   自分がスペースを打てたのかどうか目視できない。
2. 「PLAYING」という英大文字の見出しがある（サイト規約で禁止している形）。
3. 難易度ラベルに `uppercase` クラスが当たっている（日本語なので効かないが不要）。
4. ページ下部の解説文がプログラミングモードに触れておらず、日本語モードの説明しかない。
5. 「Q. スコアは保存されますか？」の回答が実装と食い違っている（保存機能は無い）。
